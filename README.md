### Roteiro de compilação:
1. Troque para src:
```bash
cd src
```
2. Compile o projeto:
```bash
gcc main.c include/TARVBMS.c include/TFOLHA.c include/TD.c include/interface.c include/relationships.c include/questoes.c -o main
```
3. Rode o projeto:
```bash
./main
```
